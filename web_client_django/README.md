# Django Web Client for FastAPI

Отдельный Django-проект, который работает с вашим API `app/main.py` по HTTP.

## Что реализовано

- Авторизация/регистрация через `api/v2/auth/*`
- Каталог недвижимости (фильтры + пагинация) и карточка объекта (фото/документы, цена/скидка)
- Панель менеджера (смена статуса, генерация договора)
- Панель админа (CRUD объектов недвижимости через FastAPI)
- Личный кабинет (история просмотров в cookie-сессии, список/скачивание договоров)
- Просмотр фото и документов объекта
- Работа с договорами (просмотр и генерация)
- Современный UI (Bootstrap + кастомные стили)

## Запуск

1. Перейдите в папку клиента:
   - `cd web_client_django`
2. Создайте виртуальное окружение и установите зависимости:
   - `python -m venv .venv`
   - `.venv\\Scripts\\activate` (Windows)
   - `pip install -r requirements.txt`
3. Создайте `.env` на базе примера:
   - скопируйте `.env.example` в `.env`
4. Убедитесь, что ваш FastAPI запущен на `http://127.0.0.1:8000`
5. Запустите Django:
   - `python manage.py runserver`

Приложение будет доступно по адресу: `http://127.0.0.1:8001` (или порту, который выберете).
